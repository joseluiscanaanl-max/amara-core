# Primeros pasos del propietario de AMARA

Las cuentas deben abrirse a nombre de AMARA y bajo un correo corporativo controlado por José Luis Canaan.

## Orden recomendado

1. Registrar el dominio definitivo de AMARA.
2. Crear correo corporativo del propietario, por ejemplo `admin@dominio-amara.mx`.
3. Crear una organización de GitHub a nombre de AMARA.
4. Activar autenticación de dos factores.
5. Crear un repositorio privado `amara-core`.
6. Subir este proyecto.
7. Crear una cuenta cloud bajo el mismo correo corporativo.
8. No contratar SMS todavía: en desarrollo se usará proveedor `mock`.

## Reglas de seguridad

- No compartir contraseñas por chat.
- No guardar llaves en el repositorio.
- Usar un administrador de contraseñas.
- Activar segundo factor en todas las cuentas.
- Conservar códigos de recuperación fuera de la computadora principal.
